РУКОВОДСТВО - HandyKopie (копирование с телефона Android, с интерфейсом)
========================================================================

ФАЙЛЫ
- Start_HandyKopie_UI.bat   -> двойной щелчок запускает программу (GUI)
- HandyKopieUI.ps1          -> сам скрипт (интерфейс)
- platform-tools\           -> adb.exe + вспомогательные DLL В КОМПЛЕКТЕ
  (Android SDK Platform-Tools, (c) Google; отдельная установка не нужна)
  ВАЖНО: всегда используйте этот .bat (НЕ старый "Start_HandyKopie.bat")!
  ВАЖНО: распакуйте всё в ОДНУ папку, иначе adb будет отсутствовать.

ПОДГОТОВКА
1. Распакуйте все файлы в ОДНУ папку.
2. Подключите телефон к ПК кабелем USB.
3. РАЗБЛОКИРУЙТЕ телефон.
4. На телефоне в панели уведомлений:
   коснитесь «Зарядка через USB» -> выберите «Передача файлов / MTP».

ЗАПУСК
Двойной щелчок:  Start_HandyKopie_UI.bat

РАБОТА
1. Слева вверху выбирается хранилище:
   - Внутренняя память  или  - SD-карта / внешнее хранилище
   (отсутствующие хранилища неактивны; после переподключения телефона
   нажмите «Обновить»)
2. В дереве папок слева ОТМЕТЬТЕ все папки, которые нужно скопировать
   (например DCIM, Download, Pictures, Documents).
   - Отметка копирует папку вместе со всеми вложенными папками.
   - Снять отметку с вложенной папки = эта папка исключается.
   - Папки раскрываются. Щелчок по папке в ЛЕВОМ дереве сразу показывает
     справа её содержимое (имена файлов с размером/датой). Двойной щелчок
     справа тоже работает; «Вверх» возвращает на уровень выше.
3. Внизу укажите ПАПКУ НАЗНАЧЕНИЯ или выберите её кнопкой «Обзор...».
4. Нажмите «Начать копирование».

ХОД РАБОТЫ
- Фаза 1: папка назначения и папки телефона сканируются (число файлов и
  размер показываются в реальном времени).
- Фаза 2: если найдены ДУБЛИКАТЫ (то же имя + тот же размер уже есть в
  назначении), появляется вопрос:
      ДА   = копировать всё равно (существующие файлы перезаписываются)
      НЕТ  = дубликаты пропускаются
  (файлы с тем же именем, но ДРУГИМ размером перезаписываются всегда.)
- Фаза 3: копирование с живым индикатором (проценты, объём, счётчик
  файлов, текущий файл).
- В конце выводится сводка (скопировано / пропущено).

ФИЛЬТР ФАЙЛОВ (СЛЕВА ВНИЗУ)
- По умолчанию: «Все типы файлов» (копируется всё).
- Или: отметьте только нужные группы, например Изображения (jpg/png/heic),
  Видео, Аудио, Документы (pdf/docx), APK, Архивы.
- Свои расширения - в маленькое поле через запятую, например «apk, pdf».

УСТОЙЧИВОСТЬ К ОШИБКАМ ПРИ КОПИРОВАНИИ
- Программа копирует файл за файлом БЕЗ блокирующих окон Windows.
- Если файл не удался (недопустимое имя, заблокирован), ошибка СРАЗУ
  записывается в текстовый файл, и работа продолжается со СЛЕДУЮЩЕГО
  файла. Процесс НЕ прерывается.
- Журнал: %TEMP%\HandyKopie_Fehler_<дата>.txt - при наличии ошибок в конце
  автоматически открывается в Блокноте; путь также виден в журнале.

ОТМЕНА
«Отмена» останавливает процесс после текущего файла.

ПРИМЕЧАНИЯ / СОВЕТЫ
- Во время копирования держите телефон разблокированным (экран включён),
  иначе соединение MTP может оборваться.
- Если программа медленно раскрывает папки: большие папки (например фото
  WhatsApp) могут содержать десятки тысяч файлов.

ОЧИСТКА: КЭШИ И МУСОР (против зависаний)
1. В главном окне слева нажмите «Очистить кэши и мусор».
2. «Сканировать» -> категории показываются с размером:
   - Миниатюры (DCIM/.thumbnails и др.)
   - Кэши приложений (Android/data/*/cache)
   - Временные/остаточные папки в корне (.cache, tmp, temp, ...)
   - Устаревшие обновления Android (остатки системных обновлений: *.ota,
     *.bin, update*.zip в корне/Download/MIUI/.ota) - если есть
3. Отметьте категории и «Удалить выбранное» -> подтвердите вопрос «Да».
   Ваши личные файлы (фото, документы, музыка, чаты WhatsApp) НИКОГДА не
   затрагиваются. Миниатюры/кэши при необходимости создаются заново.
   Примечание: начиная с Android 11 Android скрывает часть папок кэша от
   MTP (тогда показывается 0 МБ). Для этого есть кнопка «Очистить кэш
   приложений через adb»: программа сама находит adb.exe (папка скрипта,
   PATH или обычные пути установки) и выполняет
   «adb shell pm trim-caches 8G» - безопасную системную глубокую очистку
   всех кэшей приложений.
   Условие: включённая отладка по USB на телефоне.
   adb.exe уже лежит в папке platform-tools - ничего доустанавливать не
   нужно! Категории теперь показывают рядом с размером ЧИСЛО ФАЙЛОВ, чтобы
   было видно, что действительно найдено (0 = пусто или скрыто Android).

УПРАВЛЕНИЕ ПРИЛОЖЕНИЯМИ / ЧИСТОЕ УДАЛЕНИЕ
1. На верхней панели нажмите «Управлять приложениями».
2. «Загрузить список» -> показываются все сторонние приложения,
   установленные пользователем (системные приложения намеренно не
   показываются).
3. Отметьте приложение(я) и «Чисто удалить выбранное»:
   - удаляет приложение через adb (pm uninstall)
   - затем удаляет остаточные папки Android/data/<пакет> и
     Android/obb/<пакет> с телефона -> действительно ЧИСТО, без мусора
4. Условие: отладка по USB включена + ПК доверен (один раз подтвердить на
   телефоне). adb уже лежит в папке platform-tools.

ФИЛЬТР С ПОИСКОМ (справа) + ЗАГРУЗКА ОДНОГО ФАЙЛА
1. Отметьте слева внизу, например, «Аудио» или «Изображения» (или введите
   свои расширения в поле «Свои расширения» + Enter).
2. Программа АВТОМАТИЧЕСКИ обыскивает всё хранилище на эти типы файлов
   (синяя строка состояния справа вверху показывает прогресс). Кнопка
   «Искать на телефоне» запускает поиск вручную в любой момент.
   Системные папки (Android, MIUI, cache, ...) по умолчанию СКРЫТЫ -
   флажок «Показывать системные папки» включает их.
3. Справа появляется список всех ПАПОК, в которых лежат такие файлы (с
   числом и размером). Двойной щелчок открывает папку:
   - один файл: двойной щелчок (или выделить + «Копировать отмеченные»)
     -> сразу копируется в назначение
   - «Копировать папку целиком» -> копирует всю папку
4. Отметить «Все типы файлов (по умолчанию)» = поиск выключен, обычный
   браузер. «Обновить» (справа вверху) повторяет поиск.
5. Переключение вида: кнопка «Вид: миниатюры» показывает изображения/
   файлы крупными значками с предпросмотром (как в проводнике Windows),
   «Вид: список» возвращает таблицу.

РЕЖИМ КОПИРОВАНИЯ (слева, группа «Режим копирования»)
ТУРБО (adb pull):
- Флажок «Турбо (adb pull, намного быстрее)»: копирование через adb вместо
  медленного MTP - заметный выигрыш времени на многих/больших файлах.
- Условие: отладка по USB включена + ПК доверен (подтвердить один раз).
- Работает для ВНУТРЕННЕЙ памяти; для SD-карты автоматически MTP.
- Примечание: Турбо сначала полностью забирает папку на ПК и затем
  приводит её в порядок согласно выбору/фильтру - поэтому папке временно
  нужно дополнительное место на диске.
ИНКРЕМЕНТАЛЬНО:
- Флажок «Инкрементально (только новое + изменения)»: файлы, которые уже
  есть в назначении с тем же именем И размером, пропускаются БЕЗ вопроса.
  Идеально для регулярных резервных копий: второй проход передаёт только
  новое/изменённое.
- Без флажка программа при дубликатах спрашивает «да/нет» как обычно.

ПАПКА ТЕЛЕФОНА В НАЗНАЧЕНИИ
Все копии складываются в родительскую папку с именем телефона,
например  C:\Users\<вы>\Desktop\Новая папка\Redmi 12 5G\...
Так копии разных устройств остаются аккуратно разделёнными.

СОВЕТЫ, ЧТОБЫ ТЕЛЕФОН СНОВА РАБОТАЛ БЫСТРО
- После больших операций копирования/удаления: один раз перезагрузите
  телефон.
- Всегда держите свободными минимум 10-15 % памяти.
- Параметры разработчика: все 3 шкалы анимации на 0,5x (заметно плавнее).
- Удаляйте ненужные приложения или отключайте их автозапуск.
