使用手册 - HandyKopie（带界面的安卓手机复制工具）
=====================================================

文件
- Start_HandyKopie_UI.bat   -> 双击启动程序（图形界面）
- HandyKopieUI.ps1          -> 主脚本（界面）
- platform-tools\           -> 已随附 adb.exe + 辅助 DLL
  （Android SDK Platform-Tools，(c) Google；无需另行安装）
  重要：请始终使用此 .bat（不要使用旧的 "Start_HandyKopie.bat"）！
  重要：请将所有内容解压到同一个文件夹，否则 adb 会缺失。

准备工作
1. 将所有文件解压到同一个文件夹。
2. 用 USB 线将手机连接到电脑。
3. 解锁手机。
4. 在手机的通知栏中：
   点按"正在通过 USB 充电" -> 选择"文件传输 / MTP"。

启动
双击：Start_HandyKopie_UI.bat

操作
1. 左上方选择存储：
   - 内部存储  或  - SD 卡 / 外部存储
   （不存在的存储会置灰；重新连接手机后点击"重新加载"）
2. 在左侧文件夹树中勾选所有需要复制的文件夹
   （例如 DCIM、Download、Pictures、Documents）。
   - 勾选即复制该文件夹及其全部子文件夹。
   - 取消某个子文件夹的勾选 = 排除该子文件夹。
   - 文件夹可以展开。点击左侧树中的文件夹，右侧窗口会立即显示其
     内容（文件名及大小/日期）。右侧双击也可以；"< 向上"返回上一级。
3. 在下方填写目标文件夹，或用"浏览..."选择。
4. 点击"开始复制"。

流程
- 阶段 1：扫描目标文件夹和手机文件夹（实时显示文件数量和大小）。
- 阶段 2：如果发现重复文件（目标中已有同名且同大小的文件），会弹出
  询问：
      是 = 仍然复制（已有文件将被覆盖）
      否 = 跳过重复文件
  （同名但大小不同的文件始终会被覆盖。）
- 阶段 3：带实时进度条的复制（百分比、已复制量、文件计数、当前文件）。
- 结束时显示汇总（已复制 / 已跳过）。

文件过滤（左下）
- 默认："所有文件类型"（复制全部内容）。
- 或者：只勾选特定分组，例如 图片 (jpg/png/heic)、视频、音频、
  文档 (pdf/docx)、APK、压缩包。
- 自定义扩展名可填入小文本框（逗号分隔，例如 "apk, pdf"）。

复制时的容错机制
- 程序现在逐文件复制，不会弹出阻塞性的 Windows 对话框。
- 某个文件失败（例如名称非法、被锁定）时，错误会立即写入文本文件，
  并继续处理下一个文件。整个过程不会中断。
- 日志：%TEMP%\HandyKopie_Fehler_<日期>.txt - 如有错误，结束后会自动
  用记事本打开；路径也会显示在日志窗口中。

取消
"取消"会在当前文件处理完后停止任务。

提示
- 复制期间请保持手机解锁（屏幕常亮），否则 MTP 连接可能中断。
- 如果展开文件夹时程序很慢：大文件夹（例如 WhatsApp 图片）可能包含
  数万个文件。

清理：缓存与垃圾文件（防止卡顿/死机）
1. 在主窗口左侧点击"清理缓存与垃圾"。
2. "扫描" -> 各分类将显示其大小：
   - 缩略图（DCIM/.thumbnails 等）
   - 应用缓存（Android/data/*/cache）
   - 根目录下的临时/残留文件夹（.cache、tmp、temp 等）
   - 过期的安卓更新（系统更新残留：*.ota、*.bin、update*.zip，位于
     根目录/Download/MIUI/.ota）- 如果存在
3. 勾选分类并点击"删除所选" -> 在安全询问中回答"是"。
   您的个人文件（照片、文档、音乐、WhatsApp 聊天记录）绝不会被触碰。
   缩略图/缓存会在需要时自动重新生成。
   说明：Android 11 起，安卓会对 MTP 隐藏部分应用缓存文件夹（此时
   显示 0 MB）。为此提供按钮"通过 adb 清空应用缓存"：程序会自动查找
   adb.exe（脚本目录、PATH 或常见安装路径），并执行
   "adb shell pm trim-caches 8G"——由系统安全地深度清理所有应用缓存。
   前提：手机已开启 USB 调试。
   adb.exe 已随附在 platform-tools 文件夹中——无需另行安装！
   各分类现在除大小外还显示文件数量，以便看清实际找到了什么
   （0 = 为空或被安卓隐藏）。

应用管理 / 干净卸载
1. 点击顶部工具栏的"管理应用"。
2. "加载列表" -> 显示用户安装的所有第三方应用（系统应用刻意不显示）。
3. 选中应用并点击"干净卸载所选"：
   - 通过 adb 卸载应用（pm uninstall）
   - 然后删除手机上的残留文件夹 Android/data/<包名> 和
     Android/obb/<包名> -> 真正干净，不留垃圾
4. 前提：已开启 USB 调试 + 已信任本电脑（在手机上一次性确认）。
   adb 已随附在 platform-tools 文件夹中。

带搜索的文件过滤（右侧）+ 单文件下载
1. 在左下勾选例如"音频"或"图片"（或在"自定义扩展名"框中输入后按
   回车）。
2. 程序随后会自动在整个存储中搜索这些文件类型（右上方蓝色状态行
   显示进度）。按钮"搜索手机"可随时手动启动搜索。
   系统文件夹（Android、MIUI、cache 等）默认隐藏——勾选"显示系统
   文件夹"即可显示。
3. 右侧将列出所有包含此类文件的文件夹（含数量和大小）。双击打开
   文件夹：
   - 单个文件：双击（或选中后点"复制所选文件"）-> 立即复制到目标
   - "完整复制此文件夹" -> 复制整个文件夹
4. 勾选"所有文件类型（默认）" = 关闭搜索，恢复普通浏览器。
   "刷新"（右上）重复搜索。
5. 切换视图：按钮"视图：缩略图"以带预览的大图标显示图片/文件
   （类似 Windows 资源管理器），"视图：列表"返回表格视图。

复制模式（左侧，"复制模式"分组）
涡轮（adb pull）：
- 勾选"涡轮（adb pull，快得多）"：通过 adb 而非缓慢的 MTP 复制——
  文件多/文件大时明显节省时间。
- 前提：已开启 USB 调试 + 已信任本电脑（一次性确认）。
- 仅适用于内部存储；SD 卡时自动使用 MTP。
- 说明：涡轮模式会先把整个文件夹拉到电脑，再按选择/过滤整理——
  因此该文件夹短时间内需要额外的硬盘空间。
增量：
- 勾选"增量（仅新增 + 更改）"：目标中已存在同名且同大小的文件时，
  不再询问直接跳过。适合定期备份：第二次运行只传输新增/更改的
  内容。
- 不勾选时，程序对重复文件仍像往常一样询问"是/否"。

按拍摄日期整理照片
- 勾选"按拍摄日期整理照片"：复制完成后，所有已复制的 JPG 还会额外复制到
  <手机文件夹>\Fotos_sortiert\YYYY-MM\——依据真实拍摄日期（EXIF），而非
  文件日期。
- 备份结构保持不变；整理只是一个附加视图。已存在的文件不会重复复制。

目标位置中的手机文件夹
所有副本都存放在以手机名称命名的上级文件夹中，例如
C:\Users\<您>\Desktop\新建文件夹\Redmi 12 5G\...
这样不同设备的副本可以清晰分开。

让手机恢复流畅的小技巧
- 大量复制/删除操作后：重启一次手机。
- 始终保留至少 10-15% 的可用空间。
- 开发者选项：将 3 个动画缩放都设为 0.5x（明显更流畅）。
- 卸载不需要的应用，或禁用其自启动。
