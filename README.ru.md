# HandyKopie – резервное копирование Android-телефона на Windows (MTP + adb)

**Язык / Language:** [English](README.md) · [Deutsch](README.de.md) ·
[Français](README.fr.md) · [Русский](README.ru.md) · [中文](README.zh.md)

HandyKopie – бесплатная портативная утилита для Windows, которая копирует
файлы с Android-телефона (подключённого по USB/MTP, например Xiaomi/Redmi) на
компьютер – с выбором папок, поиском по типам файлов, загрузкой отдельных
файлов, инкрементальным резервным копированием, быстрым «Турбо»-режимом через
adb, очисткой телефона (кэши/остатки обновлений) и аккуратным удалением
приложений. Без установки, без облака, без рекламы – все данные остаются на
вашем ПК.

> Готовый к запуску выпуск: [`release/HandyKopie_UI.zip`](release/HandyKopie_UI.zip)
> (включая `adb`; SHA256 см. [`release/SHA256SUMS.txt`](release/SHA256SUMS.txt))

## Возможности

- **Дерево выбора папок** (слева) с флажками, включая частичный выбор
  (снятые подпапки исключаются).
- Переключение **внутренняя память / SD-карта**.
- **Браузер справа**: щёлкните папку слева – и сразу увидите её файлы;
  навигация двойным щелчком и кнопкой «Вверх».
- **Фильтр по типам файлов с поиском по всему телефону**: отметьте, например,
  *Изображения*, *Видео*, *Аудио*, *APK*, *Документы* (или добавьте свои
  расширения) и нажмите «Искать на телефоне» – будет показан список всех
  папок с найденными файлами; откройте папку, скачайте **один файл** двойным
  щелчком или скопируйте папку целиком.
- **Вид миниатюрами** (крупные значки с предпросмотром, как в проводнике
  Windows).
- **Системные папки скрыты по умолчанию** (Android, MIUI, кэши …) –
  включаются флажком.
- **Турбо-режим (adb pull)** – во много раз быстрее MTP при больших объёмах
  (внутренняя память; иначе автоматический возврат к MTP).
- **Инкрементальное копирование** – при повторном запуске передаются только
  новые/изменённые файлы; дубликаты (то же имя + размер) пропускаются без
  вопроса.
- **Определение дубликатов** с понятным вопросом «Да/Нет» (перезаписать или
  пропустить).
- **Папка телефона в месте назначения**: всё сохраняется в
  `<место назначения>\<имя телефона>\…` – несколько устройств не
  перемешиваются.
- **Устойчивость к ошибкам**: один плохой файл никогда не прерывает процесс –
  ошибки сразу записываются во временной журнал
  (`%TEMP%\HandyKopie_Fehler_*.txt`, в конце открывается автоматически), и
  копирование продолжается со следующего файла.
- **Очистка** против замедления телефона: миниатюры, кэши приложений (через
  adb `pm trim-caches`, если Android скрывает их от MTP), временные папки и
  устаревшие остатки обновлений Android – для каждой категории указываются
  размер **и число файлов**.
- **Менеджер приложений**: список установленных сторонних приложений и
  *чистое* удаление (приложение + остаточные папки `Android/data` /
  `Android/obb`).
- **Фото по дате съёмки**: JPG дополнительно раскладываются в `Fotos_sortiert\YYYY-MM` (дата EXIF).
- **Живой индикатор выполнения** (проценты, счётчики файлов, текущий файл) и
  работающая кнопка «Отмена».

## Требования

- Windows 10/11 с PowerShell 5.1 (входит в состав Windows).
- USB-кабель; телефон разблокирован; режим USB «Передача файлов / MTP».
- Рекомендуется: включить **отладку по USB** (Настройки → О телефоне →
  7 нажатий на номер сборки → Параметры разработчика → Отладка по USB) и
  доверить этому ПК – необходимо для Турбо-режима, глубокой очистки и
  менеджера приложений.
- `adb` уже в комплекте (`platform-tools/`); если удалён, скрипт
  `tools/get_platform_tools.ps1` скачает официальный пакет Google.

## Быстрый старт (3 шага)

1. Скачайте [`release/HandyKopie_UI.zip`](release/HandyKopie_UI.zip) и
   распакуйте в **одну** папку (не удаляйте `platform-tools`).
2. Подключите телефон (разблокирован, MTP), дважды щёлкните
   `Start_HandyKopie_UI.bat`.
3. Отметьте папки слева, выберите место назначения, нажмите **Копировать**.
   (При первом использовании adb подтвердите на телефоне «доверять этому
   компьютеру».)

## Безопасность и конфиденциальность

- Ваши файлы никогда не покидают ПК: прямое копирование по USB, без облака и
  телеметрии.
- Очистка и удаление приложений не затрагивают системные приложения и личные
  файлы; каждое необратимое действие требует подтверждения и протоколируется.
- Программа никогда не прерывается молча: каждая ошибка записывается с
  отметкой времени.
